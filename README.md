# zoria-client

Репозиторий заявки для турнира [ZORIA](https://zoria.net/).

## Структура

- `scripts/watch.mjs` — личный монитор эфира (не является оцениваемым
  клиентом!). Раз в 10 минут проверяет `GET /ether`, проверяет подпись
  Ed25519 конверта, и шлёт в Telegram уведомление при появлении провісника
  и при открытии просвіту. Крутится в GitHub Actions
  (`.github/workflows/watch.yml`), ничего локально держать не нужно.
- `scripts/verify.test.mjs` — офлайн-тест проверки подписи на 4 эталонных
  кадрах (A/B/C/D) из спецификации клиента. Запуск: `node scripts/verify.test.mjs`.
- `state.json` — состояние монитора (что уже отправлено в Telegram), чтобы
  не дублировать уведомления. Коммитится автоматически Action'ом.
- Основной клиент (React + TypeScript, CL-39) появится здесь отдельно —
  это то, что реально регистрируется в просвіт и оценивается организаторами.

## Настройка монитора

1. В настройках репозитория: **Settings → Secrets and variables → Actions →
   New repository secret**, добавить:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
2. Workflow запускается сам по расписанию (`cron: */10 * * * *`). Можно
   запустить вручную: вкладка **Actions → Зоря — сторож просвіту → Run workflow**.

## Локальный запуск (для отладки)

```bash
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
export ZORIA_API_BASE=https://stand.zoria.net/api/v1   # тестовый стенд, безопасно
node scripts/watch.mjs
```

## Тестовый стенд

`https://stand.zoria.net/api/v1` работает тем же протоколом, но по кругу
каждый час: `:00-:30` шум, с `:20` провісник, `:30-:50` просвіт, `:50-:00`
after. Удобно проверить весь цикл уведомлений за час, не дожидаясь
настоящего просвіту 24–25 сентября.
